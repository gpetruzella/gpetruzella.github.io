Canvas · faculty workaround

Section Limit

A bookmarklet that switches every student in a Canvas course to “can interact with users in their section only” in one pass, instead of clicking through the People page student by student.

Drag to your bookmarks bar

Limit to section

Dragging is the install. Clicking it here does nothing useful — it only works while you are inside a Canvas course.

Using it

  1. Open any page inside the course — the course home, People, Modules, anything whose address contains /courses/<number>.
  2. Click Limit to section in your bookmarks bar. It looks up every active or invited student who isn’t already limited.
  3. A confirmation asks “Limit N student(s) to their own section(s)?” Click OK to go ahead, or Cancel to leave everything as it is.
  4. Leave the tab open until a Done message appears, with a count of students updated, any failures, and how many unlimited enrollments remain (normally 0). Large courses take a few seconds per hundred students.

What it changes and what it doesn't

Changes

Sets the section-only flag on each student enrollment — the same switch as the per-student link on their People page. Limited students only see and interact with people in their own section.

Students only

Teachers, TAs, designers, and observers are left alone. Students who are already limited are skipped, so running it twice is harmless.

Checks itself

It updates one student first and re-reads that enrollment. If the flag didn't actually change, it stops before touching anyone else.

Not ongoing

Students who join later arrive unlimited — run it again after late adds. In a single-section course the flag is set but has no visible effect.

If it doesn't run

“Not on a Canvas course page”

It reads the course number from the address bar. The Dashboard, Inbox, and account pages don't have one — open a page inside the course and click it again.

“No _csrf_token cookie found”

Your Canvas session has probably expired. Reload the page (signing in again if asked), then run it.

“403 … permission denied”

Your role in this course isn't allowed to change enrollments. Ask a Canvas admin to run it, or to grant the permission.

“Aborted. The request succeeded but … flag did not change”

Canvas has probably changed the address this relies on. Nothing beyond that first student was touched. Let me know and I'll update the bookmarklet.

I want to see the details, or undo one student

Open your browser's developer console (F12) before running it: it prints a table of the students it will change and a line for each one. To reverse a single student, open them from People and use the link on their page that lets them see all course users.

Firefox blocks the bookmarklet

Some Canvas instances send a Content-Security-Policy that Firefox applies to bookmarklets. Chrome and Edge are unaffected; use one of those if it comes up.

The source

Plain JavaScript, no libraries, no network calls off the Canvas domain. It acts through your existing session — it can only change what you could already change by hand.
