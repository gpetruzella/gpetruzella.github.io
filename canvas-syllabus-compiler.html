Syllabus Compiler

A bookmarklet that gathers a Canvas page and every Canvas page it links to, stacks them in link order, and hands the result to your browser's print dialog to save as one PDF.

Drag to your bookmarks bar

Compile syllabus

Dragging is the install. Clicking it here does nothing useful — it only works while you are sitting on a Canvas page.

Using it

  1. Open the top page of the syllabus in Canvas — the one that links out to all the others.
  2. Click Compile syllabus in your bookmarks bar. A new tab opens and reports its progress as it fetches each linked page.
  3. When the compiled document appears, click Print / Save as PDF — or just press Ctrl/Cmd + P — and choose Save as PDF as the destination.
  4. In the print dialog, turn on Background graphics if any of your pages rely on colored callouts or table shading.

What it does and doesn't gather

Included

Canvas Pages and Assignments linked from the body of the starting page, in the order they appear, one section per page break.

One level deep

Pages linked from those pages are not followed. Duplicate links are collected once.

Listed, not merged

Uploaded files, quizzes, modules, and outside links land in an appendix at the end as titles and URLs. Attached PDFs still have to be merged separately.

Ignored

Course navigation and sidebar links — it only reads links inside the page content itself. Embedded video and iframes are dropped.

If it doesn't run

Nothing happened, or a pop-up warning appeared

The compiled document opens in a new tab, so the site needs permission for pop-ups. Allow pop-ups for your Canvas domain and run it again.

It says no page content was found

It looks for the Canvas content region (.show-content or .user_content). Start from a Canvas Page or an Assignment rather than a Module index or the course home page set to a module list.

Sections are missing or empty

Pages restricted by date or unpublished return nothing to the browser. Publish them, or paste those sections in by hand.

Firefox blocks the bookmarklet

Some Canvas instances send a Content-Security-Policy that Firefox applies to bookmarklets. Chrome and Edge are unaffected; use one of those if it comes up.

The source

Plain JavaScript, no libraries, no network calls off the Canvas domain. It reads through your existing session — the same pages you can already see, nothing more.
